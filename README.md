# 🏨 Hotel Room Booking System

A simple console-based **Hotel Room Booking System developed in Java** as part of Case Study 148.

## Features

- Guest Registration
- Display Room Availability
- Room Category Selection
- Room Booking
- Bill Calculation
- Stay-Based Discounts
- Checkout

## Java Concepts Used

- Arrays
- Scanner
- Switch Statements
- If-Else Conditions
- Methods
- While and For Loops
- Operators

## Room Categories

- Standard – ₹2,000/day
- Deluxe – ₹3,500/day
- Suite – ₹5,000/day

## How to Run

Compile:

```bash
javac HotelBookingSystem.java
```

Run:

```bash
java HotelBookingSystem
```

## Project Purpose

This project demonstrates the practical implementation of basic Java concepts by creating a simple hotel room booking and billing system.
